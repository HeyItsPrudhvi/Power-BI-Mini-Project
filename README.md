# Power-BI-Mini-Project
This is not a real data, This is just for practice purpose only..
A leading bike-taxi and ride-hailing platform tracks its daily bookings, rider completions, fare structures, and city-wide demand across multiple operational logs, feeding raw transactional records into a central staging environment. This raw dataset exhibits severe data quality issues, characterized by duplicate ride IDs, missing status and payment entries, inconsistent casing across vehicle types and cities, unstandardized timestamps, and unsorted chronological labels. To prevent distorted completion metrics and flawed operational planning, this project leverages Power Query to execute systematic data cleaning and standardization, constructs an optimized Star Schema data model, and aggregates key business metrics into an automated, interactive Rapido Ride & Revenue Dashboard.
